# Track B - Magnetic Wall-Climbing Robot

**首届特种机器人六周开源复现挑战赛 · 赛道B**

本项目旨在参考开源机器人项目，完成教学型永磁吸附爬壁机器人的方案设计、模块验证、机械装配、控制开发与实验分析。

团队将遵循安全优先、循序渐进、模块化验证和全过程记录的原则，逐步完成机器人复现与改进。

---

## 1. 项目目标

围绕永磁吸附爬壁机器人，完成以下工作：

- 调研并分析相关开源项目。
- 确定机器人初步技术方案和物料清单（BOM）。
- 完成机械结构与磁吸模块设计。
- 完成ESP32、电机驱动和编码器相关控制开发。
- 开展模块测试、磁吸性能测试和数据分析。
- 整理项目文档、实验记录和个人贡献证明。

**基本原则：先验证低风险模块，再开展整机实验。**

## 3. 初步技术方向与参考物料

根据手册第5章和第7章的赛道B要求，团队初步采用永磁吸附爬壁机器人方案。

### 3.1 初步系统组成

- 驱动模块：2个带编码器的减速电机及匹配驱动器。
- 主控模块：ESP32。
- 磁吸模块：可调气隙磁阵列。
- 机械模块：轮胎、轭铁及底盘打印件。
- 数据模块：编码器数据采集与实验数据分析。

## 6. 团队协作规范

1. 每项任务尽量通过GitHub Issues记录，明确负责人和完成标准。
2. 重要修改通过Commit记录，避免直接覆盖原始文件。
3. 涉及多人协作的代码和文档，尽量通过Branch和Pull Request合并。
4. 原始开源文件与自主修改文件分开保存。
5. 每位成员都需要保留真实、可核验的个人贡献记录。
6. AI生成或修改的代码必须经过人工阅读、测试和安全检查。

## 7. 安全管理要求

- 首次上电前完成安全准入和紧急停机演练。
- 未经确认，不得擅自采购或使用高风险物料。
- 电池、强磁组件及高速风机等相关操作遵循指导教师和授权人员要求。
- 电机、传感器等模块先独立验证，再考虑整机集成。
- 未通过防坠和安全审查，不开展垂直爬行实验。
- 发现磁体松动、电机堵转、异常滑移等情况，立即停止测试。
